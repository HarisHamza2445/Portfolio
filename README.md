# Portfolio

Personal portfolio of **Haris Hamza Ali**, Full Stack Developer (MERN + Generative AI), Nagpur, India.

- Particle banner built with Three.js, animations with GSAP
- Light / dark theme, responsive down to phone width
- Experience, projects (with live demos), hackathon wins, skills and education
- One-click resume download (`resume.pdf`)

## Run locally

It's a single static page. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Works as-is on Netlify, Vercel or GitHub Pages. No build step needed.
